解压后直接打开根目录 `index.html` 或 `三国杀挂机塔_双击运行.html`。游戏完全离线，无需安装依赖。

v1.2.1 将所有内容集中在首次登塔约200层内逐步解锁。初始显示登塔、武将和设置，达到节点时入口自动出现，右下角会弹出系统名称与一句用途说明。页头持续显示下一项内容及解锁层数。

分区折叠数量已经减少：只有含五个以上分区的长卡片才收纳后续内容，前两个主要分区始终直接显示；可折叠标题显示“⌄ 点击展开 / ⌃ 点击收起”。技能、词条和专业名词使用鼠标左键点击显示简短介绍，键盘与手机触摸同样支持。

飞升继续保持任意层可确认、收益实时刷新、只结算新增最高层区间。同层飞升收益为0并提前警告。存档键为 `sgs_idle_v1210`，档码前缀为 `SGST121-`，兼容v1.2.0及更早存档。

验证：`node tools/test_v121.mjs`、`python3 tools/validate_project.py`。
