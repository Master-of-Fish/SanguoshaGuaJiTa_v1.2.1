# v1.0.1 魔塔平衡调整记录

日期：2026-09-09

## 本版目标

解决 v0.20.0 中“守塔敌人长期一刀秒、层数提高但压力感不足”的问题。v1.0.1 不采用固定血墙，而是让普通层、精英层与 Boss 层都随塔层持续增长，并让高层逐渐获得更稳定的抗爆发能力。

## 已落地调整

- 敌方战力与生命改为随塔层连续指数增长，并叠加深层压力系数。
- 每 5 层精英获得额外成长；每 10 层 Boss 获得更高生命、攻防和抗性倍率。
- 随层数提高敌方减伤、抗暴、命中和穿甲等属性。
- 加入随塔层收紧的单次伤害上限，普通层 / 精英 / Boss 使用不同基础上限。
- 初始背包不再生成 18 件高层测试装备，只保留 6 件低层起步装备，避免新档直接获得远超当前层数的战力。
- 敌方战斗信息新增“塔压 · 单击上限”提示，方便观察当前层抗爆发规则。

## 实际验证

运行时抽查层数：1 / 10 / 50 / 100 / 300 / 700 / 1500。

- 敌方战力：逐层抽查严格递增。
- 敌方生命：逐层抽查严格递增。
- 单击伤害上限：随深层总体收紧；1 层普通敌人约 53.5%，1500 层 Boss 抽查约 20.1%。
- 60 次全新存档首回合模拟：首回合直接通层 0 / 60。
- 60 次样本中，首回合结束后敌方剩余生命比例平均约 70.8%，最低约 15.5%。

## 仍需继续校准

本版解决的是结构性失衡和新档“一刀秒”的明显问题，但长期挂机游戏的平衡不能只靠单一新档样本定案。下一阶段应使用不同飞升次数、装备品质、功法/灵根、武将星级的真实构筑，在 100 / 300 / 700 / 1500+ 层统计平均战斗回合数、失败率和爬层速度，再微调成长曲线。
