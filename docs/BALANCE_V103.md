# v1.0.3 魔塔平衡回归报告

## 目标

- 解决不同武将成长率在高层被指数放大造成的数量级差距。
- 缓解700～800层Boss硬墙，同时保证900层以后继续增加长期压力。
- 使用蜀/魏/吴/群各2名代表武将检查300/700/1500及700～800区间。

## 核心改动

1. 武将基础成长改为共享长期主曲线；原 `growth_attack / growth_hp / growth_defense` 只保留为有上限的身份偏差，不再直接指数累乘。
2. 700～850层Boss倍率单独校准，避免单段伤害上限叠加Boss生命后形成非机制性的硬墙。
3. 900层以后增加 `late` 长期塔压，使1500层不会反而比700层更轻松。
4. 平衡指标改为“自动挂机实际清层所需总行动数（包含失败重试）”，不再把战败后的自动重开误记为同一场战斗继续。

## 结论

- **700～800层Boss墙已明显缓解**：750与800层8名代表将全部4/4清除；中位行动数大体落在7～22之间。
- 710层仍保留一定压力：刘备、董卓样本为3/4清除，其余代表将4/4；这更接近“可能重试但不是长期卡死”。
- **1500层重新形成深层挑战**：多数武将中位约12～40行动；陆逊3/4、董卓2/4，说明深层仍需Build与成长，而不是700层后一路变轻。
- 新档首回合60次冒烟测试为0次直接过层，继续保持“不是普遍一刀秒”。
- 600级五星下32将攻击/生命/防御最大最小比约1.64/1.84/1.78，保留身份差异但不再出现成长率造成的几十倍、上百倍分化。

## 风险与后续

- 192个样本是回归矩阵，不足以替代长期挂机大样本。下一轮建议扩展到32将、不同飞升次数、不同装备品质与至少10～20个随机种子。
- 董卓与陆逊在1500层样本中清除率偏低，需观察其Build可否通过词条/功法补齐，而不是立即用纯数值上调。
