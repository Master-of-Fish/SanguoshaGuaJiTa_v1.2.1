# v1.0.4 · 32将全量平衡回归

本报告使用浏览器运行态战斗函数直接模拟，不是只比较静态战力。为避免随机机缘污染战斗曲线，回归时关闭概率事件，仅测试战斗本体。

## 样本设计

- 固定武将：32/32。
- 检查层：700 / 1000 / 1500 / 2000（均为Boss层）。
- Build：保守 / 标准 / 成型，分别配置不同武将等级、飞升次数、装备品质、灵根等级、功法等级和神兵/灵宠成长。
- 每个“武将 × 层数 × Build”执行2个确定性随机种子，总计768个样本。
- 单样本最多220次行动；战败后的自动重试计入行动数。

## 关键校准

- 900层后的旧长期压力 `1.00245^(层数-900)` 过陡，v1.0.4 调整为 `1.00095^(层数-900)`，避免1500～2000层再次形成纯数值墙。
- Boss战力倍率由旧的1.62/1.74/1.84下调为1.40/1.48/1.56；Boss生命档位由2.62/2.88/3.08下调为2.10/2.25/2.40。削减的“纯血量/纯战力”压力由三阶段Boss机制补回。
- Boss在70%与40%生命切换阶段；阶段切换后2回合出现破绽窗口，Boss承伤提高28%，同时Boss自身获得不同阶段强化。
- 董卓五星暴虐不再每次攻击必定消耗暴虐层，改善其深层生存/复起稳定性。
- 马超五星Boss突阵由0.36+0.22的追击系数下调为0.30+0.18，压低快速Build的极端爆发。

## 结论

标准Build在四个检查层的清层率分别为：700层85.9%、1000层90.6%、1500层76.6%、2000层79.7%。成型Build分别为89.1%、93.8%、90.6%、79.7%。2000层仍保留明显深层压力；保守Build在1500层后不会稳定穿透Boss，符合“需要成长/构筑升级”的定位。

这不是最终平衡终点。下一轮应增加随机词缀组合、不同飞升累计仙缘、不同主/辅功法组合，并观察2000层以上长期趋势。
