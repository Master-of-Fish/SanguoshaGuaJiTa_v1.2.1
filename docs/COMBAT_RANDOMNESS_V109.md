# v1.0.9 战斗随机性与状态层（工作版）

## 敌方数值随机波动

- 每层首次生成一组数值波动，失败重试不重抽；清层进入下一层才重新生成。
- 波动不新增独立玩法入口，只在敌方状态区显示“本层强度”。
- 敌方 HP / 攻击 / 防御 / 速度独立轻微偏移，并带均衡型、厚甲型、猛攻型、铁壁型、迅捷型五种组成。
- 概率档位目标：偏弱约20%，常态约70%，偏强约9%，极强约1%。
- Boss 的随机幅度低于普通层和精英层，避免随机数值盖过Boss阶段机制。
- 波动强度会轻微影响清层铜钱、修为和掉落倍率，强层奖励略高，弱层略低。

## 战斗状态层

### 有益状态

- 免疫控制：冻结回合、失去技能、乐不思蜀跳过行动等控制不会生效。
- 免疫死亡：持续期间首次致命伤害保留1点生命并消耗。
- 无敌：持续期间伤害归零，可被“无视状态”穿透。
- 反弹伤害：受到直接伤害后按比例反弹给来源，反伤不会无限互弹。
- 无视防御：直接攻击忽略目标主要防御/减伤。
- 无视状态：攻击或施加控制时穿透目标无敌、免死、反伤、控制免疫。

### 不利状态

- 失去技能：本回合武将技能与高星事件机制暂停，但保留基础摸牌/出牌。
- 冻结回合：本回合跳过主动行动。
- 禁疗：无法获得生命回复。
- 虚弱：造成伤害降低。
- 破防：防御/减伤效率降低。
- 迟缓：速度、闪避与响应效率降低。
- 易伤：受到伤害提高。
- 移除有益状态：即时移除1个（高强度时可移除2个）战斗Buff；无可移除Buff时改为随机Debuff。
- 随机Debuff：从控制、禁疗、虚弱、破防、迟缓、易伤、驱散中抽取。

## 来源与复杂度控制

- 普通层状态触发率很低；精英、Boss略高。
- 偏强/极强数值层会提高敌方获得临时Buff或施加随机Debuff的概率。
- 偏弱层有小概率让玩家获得一个短期正面状态。
- Boss四框架只在阶段切换时使用少量状态：破阵可驱散，守势可免控/免死，狂攻可反伤/无视防御，诡阵可随机Debuff/无视状态。
- 不新增天气、战场态势、危险值等额外模块；全部通过现有状态Chip和战斗日志表达。

## 当前验证

- JavaScript `node --check`：通过。
- Chromium运行烟测：页面脚本异常0。
- 同层失败重试：敌方数值波动保持不变。
- 10,000次波动抽样：约19.95%偏弱 / 70.27%常态 / 8.79%偏强 / 0.99%极强；五种属性组成接近均匀。
- 已验证：无敌、无视状态穿透、反伤、免控、技能封禁、Boss阶段状态、状态Chip渲染。
- 连续40次实际战斗调用：无运行异常，HP数值保持有限数。
