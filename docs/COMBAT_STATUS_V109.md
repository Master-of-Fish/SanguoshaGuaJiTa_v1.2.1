# v1.0.9 战斗状态层（30个核心状态）

## 统一规则

- 敌我双方共用同一套 `COMBAT_STATUS_DEFS + addCombatStatus/removeCombatStatus/tickCombatStatuses`。
- 每个运行态状态都记录来源、剩余回合、层数；定义层记录可驱散、可被“无视状态”穿透等规则。
- 控制类Debuff受“免疫控制”保护；“无视状态”可穿透被标记为可穿透的保护状态。
- 状态只作为现有武将/装备/神兵/灵宠/功法/Boss/层数波动的效果语言，不新增状态货币或单独养成入口。
- 敌方数值波动在进入本层时生成并固定，本层失败重试不会重抽数值。

## 18个增益状态

| 状态 | 类别 | 默认持续 | 核心效果 |
|---|---|---:|---|
| 免疫控制 | defense | 2回合 | 冻结回合、失去技能等控制状态不会生效。 |
| 免疫死亡 | defense | 3回合 / 1次 | 持续期间首次受到致命伤害时保留1点生命并消耗。 |
| 无敌 | defense | 1回合 | 持续期间受到的伤害归零；可被无视状态穿透。 |
| 反弹伤害 | counter | 2回合 | 每回合首次受到直接伤害后，反弹18%实际伤害。 |
| 无视防御 | offense | 1回合 | 本回合直接攻击忽略目标主要防御与减伤。 |
| 无视状态 | offense | 1回合 | 自身造成伤害或控制时穿透目标的无敌、免死、反伤、护盾和免控。 |
| 护盾 | defense | 3回合 | 吸收相当于最大生命14%的伤害，耗尽后移除。 |
| 必中 | offense | 1回合 | 本回合攻击不能被闪或身法闪避。 |
| 反击 | counter | 2回合 | 每回合首次受到直接伤害后，以实际伤害16%反击。 |
| 追击 | offense | 2回合 | 每回合首次造成直接伤害后追加12%追击伤害。 |
| 急速 | tempo | 2回合 | 速度提高18%，并小幅提高额外行动机会。 |
| 吸血强化 | sustain | 2回合 | 吸血提高6个百分点。 |
| 暴击强化 | offense | 2回合 | 暴击率提高10个百分点。 |
| 伤害减免 | defense | 2回合 | 受到的非持续伤害降低14%。 |
| 免疫锦囊 | defense | 2回合 / 1次 | 持续期间首次受到伤害/延时锦囊时使其无效。 |
| 免疫判定 | defense | 2回合 / 1次 | 持续期间首次不利判定或延时锦囊无效。 |
| 回春 | sustain | 3回合 | 回合开始回复3.5%最大生命，受禁疗与流血影响。 |
| 首击强化 | offense | 2回合 | 持续期间第一次直接伤害提高20%，触发后消耗。 |

| 状态 | 类别 | 默认持续 | 核心效果 |
|---|---|---:|---|
| 失去技能 | control | 1回合 | 本回合武将技能与高星事件机制暂停，仍可摸牌和使用基础牌。 |
| 冻结回合 | control | 1回合 | 本回合跳过主动行动。 |
| 禁疗 | limit | 2回合 | 持续期间无法获得生命回复。 |
| 虚弱 | stat | 2回合 | 造成的伤害降低15%。 |
| 破防 | stat | 2回合 | 防御与减伤效率降低18%。 |
| 迟缓 | stat | 2回合 | 速度、闪避与响应效率降低15%。 |
| 易伤 | stat | 2回合 | 受到的伤害提高15%。 |
| 缴械 | limit | 1回合 | 本回合不能主动使用【杀】。 |
| 禁用锦囊 | limit | 1回合 | 本回合不能主动使用锦囊牌。 |
| 灼烧 | dot | 3回合 | 回合开始损失1.8%最大生命，属于持续伤害。 |
| 中毒 | dot | 3回合 | 回合开始损失1.3%最大生命，并削弱回复效率。 |

## 获得渠道

**玩家获得增益：** 灵根、主修功法、神兵、灵宠、高品质装备、弱势层补偿。

**玩家受到减益：** 敌方层数波动、Boss阶段、敌方词缀/组合技、随机Debuff。

**敌方获得增益：** 敌方词缀、组合技、层数波动、Boss阶段。

**敌方受到减益：** 玩家灵根、主修功法、神兵会按构筑概率施加对应Debuff，例如火=灼烧、金=破防、木=中毒、水=迟缓、雷=易伤；部分功法/神兵可施加流血、禁疗、冻结、失去技能等。
