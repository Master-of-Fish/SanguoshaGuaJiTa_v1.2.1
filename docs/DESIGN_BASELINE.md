# 《三国杀挂机塔》设计基准 v1

这份文件是后续版本的“防跑偏”基准。每次加入参考项目的新玩法，都先和这里对照。

## 1. 不可妥协的初心

1. **挂机**：离线也持续成长；绝不要求玩家为了效率反复机械点击。
2. **无限成长**：塔层、战斗数值、武将等级与长期倍率理论上持续延伸。
3. **突破爽感**：卡住 → 成长 → 再回来碾过去，是游戏最重要的情绪循环。
4. **三国技能有机制感**：不把武圣、龙胆、制衡、奸雄等退化成单纯“攻击 +20%”。

## 2. 三层融合

- **修仙层**：境界、功法、装备、丹药、法宝、飞升/轮回。负责长期数值成长。
- **武将战策层**：主将、战牌、响应、转化、判定、摸弃牌。负责“怎么战斗”。
- **挂机层**：自动推塔、离线快速结算、一键管理。负责节奏与低操作压力。

## 3. 核心循环

挂机 → 修为/铜钱/灵石/装备/武魂 → 一键整理与培养 → 自动登塔 → Boss 墙 → 境界突破/换将/换装 → 突破大量层数 → 飞升/轮回 → 永久倍率 → 再循环。

## 4. UI 原则

沿用参考 `vue-idle-xiuxian` 的现代极简风：

- 现代卡片、表格、进度条、标签；信息密度高但视觉噪音低。
- 主色 `#2080F0`；品质色只用于边框、文字、角标，不铺满背景。
- 支持浅色 / 深色。
- 不做“三国杀风 UI”；三国杀只进入人物与战斗机制层。
- 一切挂机高频页面优先“一键处理”。

## 5. 更新准入规则

以后用户可以继续提供放置、修仙、卡牌、装备刷取、Roguelike 等参考项目。新玩法满足以下至少一项才进入正式规划：

- 让挂机回来更有期待；
- 让成长跃迁更明显；
- 让自动战斗更有武将差异；
- 让长期目标更清晰；
- 减少机械操作或提升信息可读性。

如果一个玩法很好但违背“挂机 + 无限成长”，先改造，不让核心跟着参考项目跑偏。

## 6. 版本更新层级

- **小更新**：新武将、新装备、新功法、平衡、主题卡池。
- **中更新**：新境界、新 Boss、新秘境/炼丹/宗门等独立模块。
- **大版本**：新的飞升世界、轮回层、战斗规则层、长期成长维度。

## 7. 存档原则

- `version` 必须存在。
- 新字段有默认值；旧版本通过 migration 升级。
- 导入前自动备份。
- 任何系统更新不得无理由要求玩家删档。
