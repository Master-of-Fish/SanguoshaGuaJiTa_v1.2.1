# 三国杀挂机塔：完整开发路线图

版本基线：v0.14.0。核心原则始终是“挂机、无限成长、自动三国杀战策、低打扰办公友好 UI”。

## A. 核心底座（持续维护）
- 数据驱动：武将、技能、牌、装备、神兵、灵宠、皮肤、秘境、Boss、掉落、数值全部数据化。
- 存档：版本迁移、导入导出、存档码、自动备份、坏档回滚。
- 大数：全战斗/资源公式为长期指数成长保留扩展空间。
- 自动化：一键升级、一键换装、一键升阶、一键分解、一键整理、自动推塔、离线结算。
- 办公模式：低动画、低饱和、可隐藏头像、远距离更像数据面板。

## B. 自动三国杀战斗
1. 继续扩充武将原味机制，减少“纯百分比被动”。
2. 手牌、牌色、点数、装备区、判定区、距离、响应链继续完善。
3. 增加更多牌：属性杀、铁索传播、酒强化、装备技能、更多延时锦囊。
4. 敌方武将同样拥有完整技能状态机与词条。
5. 增加战斗策略预设：稳健/激进/续航/锦囊优先，默认自动推荐。
6. 后期支持自动战斗回放与关键事件摘要，而不是要求玩家手操。

## C. 无限成长与轮回
1. 境界：炼气→筑基→金丹→元婴→化神→炼虚→合体→大乘→渡劫。
2. 飞升：第一层重置，保留长期资产与仙缘。
3. 后续增加第二层“轮回”、第三层“超脱”，每层重置范围不同。
4. 每个长期层级都给新的规则解锁，而不只是乘区。
5. 塔层保持理论无限，Boss墙 + 快速碾压交替。

## D. 仙途
1. 灵根 Lv.20 后追加觉醒节点与双灵根。
2. 主/辅功法继续增加，支持品质、残页、突破、专属词条。
3. 命格增加稀有词条、锁词重铸、命格套组。
4. 武将×灵根×功法联动扩展至全部武将，并支持多种 Build。
5. 功法掉落不增加新货币，使用残页材料。

## E. 秘境 / 周期 PVE
1. 每日秘境：低频点击、可扫荡。
2. 周期Boss：每日/每周轮值，展示完整武将技能与词条。
3. 世界事件：不联网也能本地轮换的周期主题。
4. 三国章节副本：赤壁、官渡、夷陵等，作为长期内容模块。
5. 无尽试炼：不同规则修正，奖励长期材料。

## F. 武将

- 武将总数永久固定为 **32名**。
- 不再通过新增武将扩内容；重点深化现有武将的等级、武魂星级、技能词条、专属神兵、皮肤、仙途联动和敌方变体。
- 普通/界/神/谋等变体若未来需要，只作为同一武将的技能形态或皮肤/挑战形态，不增加可收集武将槽位。

## G. 装备 / 神兵
1. 普通装备保持海量掉落 + 一键管理。
2. 扩充词条：格挡、反击、技能触发、异常命中/抗性、最终伤害/减伤、斩杀、回复效率。
3. 词条稀有度、极品词条、词条锁定、重铸。
4. 套装只做轻量 2/4 件效果，不让背包管理变复杂。
5. 神兵继续作为低频长期资产，增加共鸣、专属武将联动和外观。

## H. 灵宠
1. 灵宠升级、灵契、出战被动继续保留。
2. 增加挂机型、战斗型、掉落型、回廊型定位。
3. 后期支持灵宠天赋树，但默认提供一键推荐。

## I. 回廊皮肤
1. 25格阵盘规则固定：1抽/10抽同算法、12连线、25种全亮才能使用。
3. 皮肤不加战力，保持纯收藏。
4. 增加筛选、搜索、收藏完成度、随机换肤、已解锁轮播。
5. 以后可做主题回廊活动，但不改变基础概率规则。

## J. 抽卡
1. 武将、神兵、灵宠保持独立池。
2. 心愿单、阵营池、主题池、保底继承。
3. 重复永远有价值，但后期收益递减。
4. 皮肤不再走普通抽卡，统一走回廊。
5. 抽卡资源必须始终存在稳定免费获取渠道。

## K. 资源与经济
- 正式货币只维持少量核心货币：铜钱、灵石、仙缘、回忆令。
- 新系统优先使用材料而不是新增货币。
- 顶栏展示全部货币，悬浮说明获取渠道与用途。
- 所有货币必须至少有一个可重复免费获取渠道。
- 建立内部经济模拟，检查第1小时/1天/7天/30天节奏。

## L. 挂机体验
1. 离线收益上限与效率可通过成长系统提高。
2. 离线不逐帧模拟牌局，而用统计模型近似。
3. 回来后给“收益摘要”：层数、装备、货币、残页、稀有事件。
4. 自动清仓：升阶→筛选→换装→分解。
5. 目标是上班族每天短时间收菜，不要求长时间盯屏。

## M. 图鉴 / 成就 / 统计
- 武将、牌、神兵、灵宠、装备词条、皮肤、Boss图鉴。
- 成就提供少量永久成长或收藏奖励。
- 战斗统计：胜率、Boss卡点、技能触发率、牌型分布。
- 掉落统计：过去1小时/今天/本次飞升周期。

## N. 内容更新方式
- 小版本：武将、平衡、神兵、灵宠、皮肤、秘境掉落。
- 中版本：新系统模块、境界、章节、副本、装备词条。
- 大版本：新的轮回层与长期世界。
- 用户后续上传参考项目时，先提炼“它解决了什么需求”，再按本项目核心循环改造，不直接照搬。

## O. 技术与发布
1. 继续同时提供完整项目 ZIP + 根目录 index.html 双击入口。
2. HTML 入口优先用于快速试玩；Godot 项目骨架继续保留。
4. 如果后期公开/商业发布，三国杀官方素材、皮肤、技能原文需单独处理授权/原创化。
5. 在内容量扩大前先做性能：分页、懒加载、皮肤缩略图缓存、存档压缩。

## P. 近期版本顺序建议
- v0.13：秘境、周期Boss、功法品质、派遣、收益统计。
- v0.14：离线收益摘要、扫荡、装备词条锁定/重铸、武将适配推荐。
- v0.15：48名武将、更多原味技能、属性杀/铁索传播。
- v0.16：图鉴、成就、Boss专属掉落、章节副本雏形。
- v0.18：回廊精选档案完全本地化、搜索筛选、随机换肤。
- v0.18：第二层轮回系统雏形与长期数值模拟。


## v0.15 起的固定约束
- 武将永久固定 32 名，不再扩容。
- 仙缘必须同时承担永久成长与可消费用途。
- 装备随机性必须配套锁词、重铸和一键管理，避免上班族重复操作。
