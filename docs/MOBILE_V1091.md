# v1.0.9.1 · 手机浏览器适配验收

针对此前“PC正常、手机客户端界面异常”进行响应式热修。页面仍完全离线，不引入移动端框架或网络依赖。

## 适配内容

- 顶部操作区改为窄屏纵向布局；主导航改为触控横向滚动。
- 表单/按钮触控高度、16px输入字号、卡片间距和两列/单列断点统一。
- 登塔、机缘、商城、成就、武将、装备、回廊、设置等16个页面均提供窄屏布局。
- 装备页在手机端保持角色/六槽可读结构，并避免横向溢出。
- Tooltip在触屏设备支持点击打开/再次点击关闭；不依赖鼠标hover。
- 加入 `viewport-fit=cover` 与安全区兼容，允许用户缩放。
