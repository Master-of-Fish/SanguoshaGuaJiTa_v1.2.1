# v1.0.9 · 333机缘质量统计

本版不增加事件数量。使用运行时实际选择器连续模拟 **10,000次普通机缘**，覆盖正式333件池，统计17类机制、锋行/守成/经营倾向、路线记忆命中、连锁命中和直接收益。

## 核心结果

- 唯一事件名称：333/333；唯一描述：333/333。
- 锋行/守成/经营实际触发占比：35.2% / 30.3% / 34.4%。
- 路线记忆命中率：51.6%。
- 连锁命中率：2.50%。
- 有舍有得事件占比：28.8%。
- 相邻两次同类机制连续出现率：0.34%。

## 本版整理策略

v1.0.8虽然已经把333件事件重写成唯一名称/描述，但实测三种长期倾向仍偏向锋行。本版选择器加入**软均衡**：在不破坏路线记忆优先级的前提下，轻微提高当前存档中低频倾向的候选权重；同时继续对最近3类机制做反重复评分。10,000次模拟后，三倾向从此前约44.1% / 20.0% / 35.9%收敛到约35.2% / 30.3% / 34.4%，相邻同类重复率约0.34%。

直接收益平均值只表示事件主效果，不含连锁、长期倾向或临时属性折算，因此不能直接作为完整战力价值。
