# v0.20 外部资料独立分析与整合记录

本文件记录本次三份资料的**独立解包结果**与最终整合边界。第三方资料用于学习、校对和素材筛选，不作为在线运行依赖。

## 1. LuaSkillsForQSGS-master

- 已完整展开：51个文件，约1.6MB。
- 类型：28个 `.lua`、23个 `.md`，主体按技能拼音 A～Z 编排。
- 静态扫描约见：378处 `CreateTriggerSkill`、131处 `CreateSkillCard`、82处 `CreateViewAsSkill`。
- 高价值内容：触发时点、回合阶段、牌使用/响应、伤害前后、改判、牌移动、濒死/死亡、技能标记、次数限制、子技能组织。
- 不整合：QSanguosha Lua API、本体运行框架、第三方技能源码直接复制。
- v0.20 用法：抽象为本项目自己的技能阶段、条件、标记和事件思路，再用 JavaScript 实现。

## 2. sgs-wiki-main

- 已完整展开：64个文件，约5.1MB。
- 类型：离线 Wiki 数据、JSON/JS/MJS 规则原型和文档。
- `prototype/shared/generals.json` 约698条武将记录；固定32名目标武将均能在资料中找到对应语义参考。
- 同包包含派生技能/卡牌数据、约58条装备记录和 `room-logic.mjs` 等房间逻辑原型。
- 高价值内容：技能“是什么”、卡牌/装备术语、体力/势力信息、规则状态、房间结算结构、历史版本差异。
- 不整合：外链图片、在线抓取、Wiki页面本身以及任何网站依赖。
- v0.20 用法：与 LuaSkills 互补，用来校对技能身份机制和卡牌事件语义。

## 3. 16武将皮肤.rar

### 原始包概况

- RAR5，完整解出572/572个文件，失败0。
- 展开总量约252.4MiB（文件系统占用约254MB）。
- 覆盖16名：关羽、张飞、赵云、诸葛亮、曹操、司马懿、郭嘉、甄姬、孙权、周瑜、陆逊、孙尚香、吕布、貂蝉、张角、华佗。
- 共47套皮肤：关羽3套、华佗2套，其余14名各3套。
- 文件类型统计：249 PNG、154 atlas、144 skel、10 JSON、13 MP3、1 TXT、1 INI。
- 47/47套均检测到 Spine 骨骼资源，因此该包本质上是动态皮肤资料包；没有独立的“纯静态皮肤套”。
- 检出2组完全重复资源，可在后续继续去重。

### v0.20 正式精选

- 为控制体积，按每名武将2套构建第一版精选，共32套动态皮肤。
- 精选资源约105.5MB（未压缩文件体积）；完整路径记录在 `data/skin_selected_v020.json`。
- 原始47套元数据与资源统计记录在 `data/skin_source_index_v020.json`。
- 所有MP3均排除，不进入运行目录；游戏无语音、无BGM。
- 每套精选记录 `combat_bonus = 0`，只提供外观。
- 解锁方法固定为 `memory_grid_25`；皮肤不进入普通召唤或掉落。

### 动态格式与播放说明

- 源素材同时存在 Spine binary（`.skel + .atlas + .png`）和少量 Spine JSON（`.json + .atlas + .png`）。
- v0.20 保留所选皮肤的完整本地 Spine 源文件，并在 HTML 端使用本地 PNG 图层提供静音循环动态预览；`playDynamicSkins=false` 或办公模式会暂停该视觉。
- **注意**：v0.20 的浏览器端预览是离线图层运动预览，并非完整 Spine 骨骼 runtime 的动作还原。完整骨骼动画播放器被列为 v0.21 的明确工程项；源骨骼数据已保留，后续无需重新获取资料包。

## 4. 整合边界与风险

- Lua/Wiki：仅学习机制与语义，不整体复制第三方工程。
- 皮肤：只选用本地精选资源；不包含任何下载器、网页跳转或远程素材地址。
- 素材授权：这些皮肤来自用户提供的资料包；项目包可用于本次离线开发/测试。若要对外公开分发，仍应由项目持有人确认相应素材的再分发授权。
- 完整离线是硬要求；所有正式运行路径均为相对本地路径。
