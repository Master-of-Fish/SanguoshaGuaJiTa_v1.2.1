# v1.2.0 热修说明

## 飞升

飞升在任意最高层均可确认。预览与结算使用同一函数，并每500毫秒刷新。第一次结算当前最高层对应的完整曲线收益；后续只结算上次飞升后新增最高层区间，再应用 `1 / (1 + 0.25 × 已飞升次数)` 衰减。同层重复飞升收益为0，但会增加飞升次数，确认按钮会明确警告。

所有养成、塔层、资源和战斗状态均保留。v1.1.1 的已结算永久收益和更早版本的旧永久倍率原样迁移。

## 界面

卡片长说明改为可悬停、聚焦或触摸打开的帮助提示。页面分区可折叠，长列表使用限制高度的局部滚动，减少整页上下滑动。技能、词条和常见战斗术语自动附加简短解释。手机按钮与折叠标题的最小点击高度为44px。
