# v1.2.1 热修说明

## 200层内逐步解锁

| 最高层 | 解锁内容 |
|---:|---|
| 1 | 登塔、武将、设置 |
| 10 / 20 / 30 | 修炼、背包、寻访 |
| 45 / 60 / 75 | 装备、神兵、灵宠 |
| 90 / 110 / 130 | 仙途、机缘、商城 |
| 150 / 170 | 秘境、成就 |
| 185 / 200 | 战策、回廊皮肤 |

每次解锁在右下角显示5.2秒提示，包含系统名称和一句功能说明。老存档按历史最高层直接开放，加载时不会重复轰炸提示。

## 精简界面与说明

只有至少五个静态分区的长卡片会折叠，前两个主要分区保持展开。折叠标题明确显示展开或收起操作。长列表继续使用局部滚动以控制页面高度。

术语、技能和词条使用左键点击开启说明，再次点击关闭；键盘Enter、空格和手机触摸均可操作。说明保持简短，并沿用现有悬浮层，避免增加正文高度。
