## 验证口径

- 24名全部存在玩家侧事件挂钩；定向运行测试均触发到3/4/5星事件轨迹。
- 24名全部存在敌方高星分支；玩家与敌人继续读取同一套 `skill_versions` 星级数据。
- 连同 v0.20 已深入实装的关羽、张飞、赵云、曹操、司马懿、孙权、吕布、张角，当前32名正式武将均进入事件级高星技能框架。
