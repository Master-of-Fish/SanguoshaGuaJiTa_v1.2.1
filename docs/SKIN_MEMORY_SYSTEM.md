# 25格皮肤回忆阵盘（v0.6.0）

## 核心规则
- 每款非基础皮肤拥有独立 5×5 阵盘，共 25 种碎片。
- 回忆1次：消耗1枚回忆令，获得1个碎片。
- 回忆10次：消耗10枚回忆令，**严格等价于连续执行10次回忆1次**。没有十连保底、没有十连概率修正。
- 每种碎片允许重复获得，格子右上角显示累计次数。
- 横向5条 + 纵向5条 + 两条对角线，共12条连线。每条奖励只领取一次。
- 25种碎片全部至少点亮1次后，皮肤才解锁并允许换肤。
- 基础头像始终可使用。

## 概率解释
用户提供的表按“目标第N种不同碎片”实现。比如当前已有24种不同碎片时，下一抽获得第25种新碎片的概率为0.29%；未命中新碎片时，只从已经点亮的碎片里随机一个重复碎片。

精确概率保存在 `data/skin_memory.json`。

## 回忆令（原型）
- 新档初始30枚。
- 每突破50层获得1枚。
- 测试资源按钮额外发放1000枚，方便测试最后几枚低概率碎片。
正式发行时可再接活动、成就、签到等来源。
