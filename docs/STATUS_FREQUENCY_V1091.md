# v1.0.9.1 · 30状态频率观察

重点观察高影响状态：无敌、免疫死亡、冻结回合、失去技能、无视状态。每个层级抽取4000次战斗初始化，合计16000次。

| 层数 | 玩家侧出现任一重点状态 | 敌方侧出现任一重点状态 |
|---:|---:|---:|
| 100 | 0.750% | 0.675% |
| 5500 | 0.925% | 0.575% |
| 6500 | 0.925% | 0.600% |
| 8000 | 0.650% | 0.900% |

单个重点状态在任一4000次批次中的自然出现次数均不超过22次（≤0.55%）。随机状态权重已将无敌、免死、冻结、失去技能、无视状态置于低权重；普通机缘的战斗余韵池明确排除这5种高影响状态。

该统计只用于观察随机来源频率；玩家主动选择特定灵宠/神兵/Build所获得的确定性或半确定性状态属于构筑价值，不应和随机频率混为一谈。
