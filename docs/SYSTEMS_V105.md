# v1.0.5 系统更新说明

## 事件连锁

事件总量继续固定为：**39件普通概率事件 / 29件厄运三选一 / 6件幸运事件**，没有增加第40件普通事件。

本版在既有事件之间加入8条连锁线索。前置事件发生后，线索最多保留80层；线索存在时，对应后续事件有42%优先命中机会。完成后续事件会追加连锁结果并记录事件连锁次数。

厄运三选一还会留下20层路线倾向：强攻、稳守、商路。后续普通/幸运事件会根据路线追加不同得失，让一次厄运选择真正影响后面的爬塔过程。

## Boss四类牌局规则

Boss仍为3阶段，在70%和40%生命切换阶段，并给予2回合破绽窗口。

- **破阵**：阶段转换积累装备压制；敌方行动时降低防具效率，并可绕过白银狮子的单次保护。
- **守势**：阶段2起每个Boss回合刷新锦囊护幕；首个伤害锦囊被压到38%，玩家用【杀】可以先击破护幕并制造轻微破绽。
- **狂攻**：阶段2起统计玩家连续【杀】，每2次可触发反击；阶段3开启2回合禁疗，桃、吸血和通用治疗都受该状态约束。
- **诡阵**：阶段2起每逢偶数Boss回合进行判定；黑色结果降低本回合摸牌，红色结果让阵眼暴露并形成短破绽。

## 固定10格商城战力预估

商城仍固定10格，且永远不出售皮肤。

装备商品在刷新时就生成具体装备，购买时得到的就是卡片上预览的那件；灵宠商品也固定具体灵宠和目标等级。界面用临时模拟方式计算“假设立即装备/启用后”的当前战力，再恢复原状态，显示 `预计当前战力 +X.XX%`。资源类商品明确显示“不直接计入当前战力”。

## 装备同槽双栏比较

装备页新增：

- “一键只看升级件”；
- 当前同槽 vs 候选装备的双栏对比；
- 品质、品阶、适配度与最多6项主要属性；
- 适配变化的绝对值和百分比；
- 原有部位/品质筛选、适配/评分/品质排序继续保留。
