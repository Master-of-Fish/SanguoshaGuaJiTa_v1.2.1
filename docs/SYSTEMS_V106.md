# v1.0.6 系统更新说明

## Boss规则与AI

- 破阵：阶段转换施加装备压制；AI会优先重新装备完成整备，清除压制并制造短破绽。第三阶段不再重复堆叠2层压制，减少5000层硬克制。
- 守势：阶段2+存在锦囊护幕；AI识别护幕后优先用【杀】撕盾，再释放高价值伤害锦囊。
- 狂攻：追踪连续【杀】并反击；AI会主动用锦囊/装备打断连杀节奏；第三阶段禁疗缩短为1回合。
- 诡阵：偶数Boss回合判定；黑色干扰牌序，红色暴露阵眼形成短破绽。

## 3000层三将定向修正

- 甘宁：奇袭选牌排除桃/闪/无懈等保命资源；2次奇袭形成夜袭印并回收1张战利牌；五星Boss首次锦帆破阵可直接拆除破阵压制。
- 张角：Boss战加入主动天公引雷周期；失败积累雷势，4星可主动重判，5星黑桃追加雷狱连锁。
- 董卓：五星Boss受创可补充暴虐；暴虐护身对高层单次伤害更稳定；低血可用暴虐承受崩坏；酒池可在低血时回气，仍受Boss禁疗规则约束。

## 事件链第二轮

39 / 29 / 6 的事件总数保持不变。普通事件连锁从8条扩展为12条，其中新增四条三段长线：铸锋、悟道、商路、行路。三段终点根据强攻 / 稳守 / 商路路线结算互斥结果，终点完成后进入120层冷却，再允许重新开启该长线。

## 商城构筑预估

固定10格不变。装备商品会显示预计替换的槽位与“当前装备 → 商品装备”；灵宠商品显示“当前灵宠 → 目标灵宠”。资源商品明确标注不会自动替换当前构筑。战力提升百分比继续由临时模拟当前Build计算。

## 装备构筑UX

保留同槽双栏比较与“一键只看升级件”，新增候选卡片“快速穿戴”和“批量穿戴升级件”。批量操作遵守当前部位/品质筛选，只替换适配度实际更高的同槽装备。
