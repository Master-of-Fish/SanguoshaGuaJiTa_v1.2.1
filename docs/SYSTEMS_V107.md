# v1.0.7 系统更新说明

## 机缘

- 普通机缘扩展至 **333件**；29件厄运三选一与6件幸运事件继续保留。
- 机缘卡直接显示货币、修为与临时属性的详细数值变化。
- 四条三段长线继续保留，并新增180层路线记忆；终点选择会影响后续相关机缘。

## 商城

- 永久固定 **10格**，继续禁止皮肤商品。
- 装备/灵宠商品显示预计战力变化、预计替换对象与详细属性差额。
- 资源商品明确显示实际资源变化。

## 成就

- 总量扩展至 **999条**：简易333 / 中等333 / 困难333。
- 每页30条，支持难度筛选和翻页。
- 成就页新增 **“一键领取可领成就”**：一次领取当前所有已完成、未领取奖励；若领取奖励本身又解锁后续成就，会继续结算直到没有新的可领取成就。
- 设置页的总“一键领取”继续包含离线收益、成就奖励与已完成派遣。
- 成就奖励只使用现有正式货币，不新增成就币。

## Boss

- 保留破阵 / 守势 / 狂攻 / 诡阵四框架和三阶段机制。
- 32名固定武将各有一套Boss专属战策签名，与四框架组合，减少“只换名字”的感觉。
- 深层诡阵干扰和回复型专属Boss进行了公平性收敛。

## 构筑UX

- 商城显示战力提升来源和具体替换槽位/灵宠。
- 装备批量换装先显示替换预览，再执行真实升级件替换。
- 武将招募展示32名固定武将头像。

## 设置与存档

- 兑换码入口继续保留，但不在界面提示具体兑换码内容。
- 存档升级为 `sgs_idle_v1070` / `SGST107-`，兼容此前正式档码。
- 浏览器标题继续固定“金山文档”，项目保持完全离线。
