# v1.0.8 系统更新说明

## 333机缘质量整理

- 总量保持 **333普通机缘 + 29厄运 + 6幸运**，本版没有继续机械增加数量。
- 39件基础机缘保留；294件扩展机缘重新整理为14个场景主题、21种事件场景、17类实际机制。
- 333件普通机缘现在拥有 **333个唯一名称与333条唯一描述**，不再使用“主题·01 / 主题·02”式流水编号。
- 扩展机缘按锋行 / 守成 / 经营三类长期倾向记录；同类倾向累计6次会形成60层长期结果。
- 既有四条三段事件长线、180层路线记忆、强攻/稳守/商路互斥结果继续保留；路线记忆还会与扩展机缘倾向产生小幅共鸣。
- 机缘卡继续显示铜钱、灵石、修为、回忆令及攻防/暴击/穿甲等详细数值变化。

## 999成就UX

- 新增 **“只看可领取”** 筛选。
- 新增 **“最近完成”** 排序；v1.0.8开始记录成就首次检测到完成的时间。
- 一键领取后显示 **本次奖励汇总**：领取项数，以及铜钱 / 灵石 / 仙缘 / 回忆令总量。
- 原有成就页“一键领取可领成就”继续支持级联领取；设置页总“一键领取”继续包含成就。
- 999条成就与简易/中等/困难各333条的数量不变，每页30条以控制渲染负担。

## 8000层内平衡校准

- 按最新决定，常规平衡矩阵最高只跑到8000层，不继续向更深层扩展。
- 深层成长对累计仙缘/飞升的有限破限空间小幅提高，让标准与极品Build不再被单段限制完全压成同一胜率。
- 6000～8000层最低敌方进攻压力做温和校正，保持挑战但减少机制外的硬压。
- 陆逊、许褚、于吉、吕布、甘宁做机制级深层稳定性修正，不采用统一伤害倍率补偿。
- 5500/6500/8000共1152个运行态样本已重新跑完，详情见 `BALANCE_V108.md`。
