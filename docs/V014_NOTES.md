# v0.14.0 设计说明

## 武将数量
固定32名，不再增加。后续版本只深化技能、武魂、神兵联动、皮肤与数值构筑。

## 仙缘
- `fate`：当前可消费仙缘。
- `fateTotal`：累计获得仙缘，永久倍率按此计算。
- 战意道印：每级攻击+4%、技能效果+3%。
- 静修道印：每级挂机收益+6%。
- 天运道印：每级幸运+5、装备掉落+2%。

## 武魂
技能数值倍率：1星1.00 / 2星1.10 / 3星1.22 / 4星1.36 / 5星1.52。
每高一星同时增加2.5个百分点的技能触发率修正；核心自动战策已接入。

## 装备分解
用户选择最高分解品质。所有未装备、未锁定且品质不高于阈值的装备都会彻底从背包数组移除。

## 精英层
每5层但非10层Boss层为精英层。精英敌人拥有2个随机词条，并可从其对应回廊皮肤中随机选择展示。
