# v0.16.0 更新说明

## 方向
- 武将数量固定 32 名，不再增加。
- 继续深化现有武将、装备与仙缘长期成长。

## 5星觉醒词条
每名武将达到5星后可从三条觉醒词条中选择一条：
- 破阵：偏技能倍率、破甲、Boss攻坚。
- 疾策：偏技能触发率、速度、命中。
- 守心：偏最大生命、抗暴、吸血。

觉醒词条会进入真实战斗数值与技能倍率结算，可随时重新选择，不额外消耗稀有资源。

## 一键培养当前武将
一键培养只消耗：
- 铜钱：升级武将等级。
- 已持有武魂：连续进行可完成的武魂突破。

不会自动消费灵石、仙缘或回忆令。若已拥有推荐神兵，会自动装备推荐神兵。5星首次培养时默认选择“破阵”觉醒词条，之后可手动切换。

## 极品装备保护
系统会根据品质、词条数值和Boss专属标记识别极品装备。
- 默认“一键分解保护极品”开启。
- 默认“新掉落极品自动锁定”开启。
- Boss专属装备永远视为极品。
- 两项设置均可在背包页面关闭。

## Boss专属装备
- 每10层Boss：15%概率额外掉落1件镇塔专属装备。
- 每100层Boss：必掉1件镇塔专属装备，且最低传说品质。
- 专属装备固定带更高Boss伤害和破甲词条。

## 仙缘商店
消费的是“可用仙缘”，不会减少累计仙缘，因此不会降低永久飞升倍率。
可兑换灵石、回忆令、功法残页、当前主将武魂和镇塔宝匣。

## 保持不变
- 武将总数：32。
- 每清除20层固定获得1枚回忆令，跨层累计补发。
- 回廊皮肤25格阵盘规则不变。
- 完整项目ZIP + 根目录 index.html 双击运行。
