# 三国杀挂机塔 v0.7.0

双击 `index.html` 或 `三国杀挂机塔_双击运行.html` 即可试玩。

## v0.7.0 内容扩充
- 武将：32名（新增马超、庞统、甄姬、荀彧、大乔、太史慈、于吉、左慈）
- 神兵：20件
- 灵宠：16只
- 战策图鉴：5种基本/响应牌 + 14种锦囊/延时锦囊
- 新增：乐不思蜀、兵粮寸断、闪电、铁索连环、万箭齐发、桃园结义、五谷丰登、借刀杀人等自动战斗逻辑
- 保留：25格回忆阵盘、12条连线、全碎片解锁后换肤、一键背包、自动挂机、飞升、导入导出存档

项目已内置你提供的 `sgs_bwiki_heros` 与 `sgs_bwiki_skins` 下载器（保留原 LICENSE/README）。
在有网络的 Windows 电脑上可运行：

`tools/bwiki/下载首批素材.bat`

它会下载当前32名武将的经典形象与静态皮肤、故事/台词元数据，然后调用 `tools/import_bwiki_content.py` 导入到 `assets/skins/`、`data/skins.json` 并重建 HTML。
